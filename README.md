# Ημερολόγιο ΟΜΗ

Η δημόσια εφαρμογή προβάλλει το τελευταίο δημοσιευμένο πρόγραμμα. Η διαχείριση γίνεται από την ίδια διεύθυνση, με ξεχωριστή σύνδεση για κάθε διαχειριστή. Η διεπαφή και οι κανόνες υπολογισμού βασίζονται στην εγκεκριμένη v10.7.

## Τοπική δοκιμή

Απαιτείται Node.js 24 και Bash. Χρησιμοποιήστε συνθετικά δεδομένα σε κάθε δοκιμαστική εγκατάσταση. Ο διακομιστής ξεκινά με άδειο ιδιωτικό πρόχειρο και άδειο δημόσιο ημερολόγιο.

```bash
read -rsp 'Κωδικός δοκιμής (τουλάχιστον 16 χαρακτήρες) ' OMH_ADMIN_PASSWORD
printf '\n'
printf '%s' "$OMH_ADMIN_PASSWORD" | node scripts/admin.js set admin
unset OMH_ADMIN_PASSWORD
LOCAL_TEST=1 npm start
```

Ανοίξτε [την τοπική εφαρμογή](http://127.0.0.1:3000). Πατήστε **Διαχείριση** και συνδεθείτε ως `admin`. Η τοπική δοκιμή είναι διαθέσιμη μόνο στον ίδιο υπολογιστή. Η δοκιμή από πολλές συσκευές χρειάζεται εγκατάσταση HTTPS.

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

Για εγκατεστημένο Chromium, χρησιμοποιήστε `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`.

## Εγκατάσταση HTTPS

1. Επιλέξτε διαρκώς διαθέσιμο διακομιστή με ιδιωτικό μόνιμο τόμο. Δημιουργήστε λογαριασμό υπηρεσίας χωρίς δικαιώματα διαχειριστή. Εκτελέστε την εφαρμογή μόνο με τον λογαριασμό υπηρεσίας.
2. Τοποθετήστε τη βάση και το αρχείο χρηστών στον ιδιωτικό τόμο, εκτός καταλόγου εξυπηρέτησης. Ρυθμίστε τις απόλυτες διαδρομές `DB_PATH` και `ADMIN_FILE`. Δημιουργήστε λογαριασμό για κάθε διαχειριστή με το εργαλείο της τοπικής δοκιμής. Αλλαγή κωδικού ή αφαίρεση λογαριασμού τίθεται σε ισχύ μετά από επανεκκίνηση της υπηρεσίας. Η διαδρομή και τα αρχεία πρέπει να είναι προσβάσιμα μόνο στον λογαριασμό υπηρεσίας και στον τεχνικό εγκατάστασης.
3. Ορίστε `ORIGIN` στην ακριβή διεύθυνση HTTPS, π.χ. `https://calendar.example.org`, χωρίς τελικό `/`. Εκτελέστε `npm start` με επανεκκίνηση από τον διαχειριστή υπηρεσιών του συστήματος. Η προεπιλεγμένη θύρα είναι 3000 στο loopback. Το `LOCAL_TEST` χρησιμοποιείται μόνο στη δοκιμή μέσω HTTP.
4. Τερματίστε το TLS σε reverse proxy που προωθεί στο `127.0.0.1:3000`. Για παράδειγμα, με Caddy και έγκυρο DNS:

   ```caddyfile
   calendar.example.org {
       reverse_proxy 127.0.0.1:3000
   }
   ```

5. Ελέγξτε τη σύνδεση από δεύτερη συσκευή, τη δημιουργία αντιγράφου εκτός διακομιστή και τη δοκιμαστική επαναφορά. Χρησιμοποιήστε διαφορετική βάση, λογαριασμούς και διεύθυνση για προπαραγωγή. Εισαγάγετε το πραγματικό JSON μόνο μέσω της εγκεκριμένης ιδιωτικής διαχείρισης μετά την αποδοχή της υποδομής.

## Αντίγραφα και ανάκτηση

- Το **Εξαγωγή JSON** αντιγράφει τις καταχωρίσεις του τρέχοντος πρόχειρου και διατηρεί τη μορφή v10.7. Κατεβάστε το πριν από εισαγωγή, εκκαθάριση ή μαζική αλλαγή. Φυλάξτε το σε ιδιωτικό, ελεγχόμενο χώρο. Το JSON λειτουργεί μέσω **Εισαγωγή JSON**. Η εισαγωγή παραμένει πρόχειρο μέχρι να τη δημοσιεύσετε.
- Από **Ιστορικό δημοσιεύσεων**, η **Επαναφορά δημοσίευσης** δημιουργεί νέα έκδοση με το αποθηκευμένο δημόσιο στιγμιότυπο και το όριο της επιλεγμένης έκδοσης. Το πρόχειρο παραμένει ανεξάρτητο.
- Ο τεχνικός εγκατάστασης μπορεί να προγραμματίσει καθημερινό συνεπές αντίγραφο της SQLite με `npm run backup -- /private-backups/calendar-YYYYMMDD.sqlite`. Αποθηκεύστε το κρυπτογραφημένο εκτός διακομιστή. Η πλήρης βάση περιέχει ιδιωτικές καταχωρίσεις, ιστορικό και συνεδρίες. Διατηρήστε χωριστό, ιδιωτικό αντίγραφο του αρχείου διαχειριστών.
- Για πλήρη ανάκτηση, δοκιμάστε πρώτα το αντίγραφο σε απομονωμένη εγκατάσταση με δικούς της λογαριασμούς. Σταματήστε την υπηρεσία και διατηρήστε την προηγούμενη βάση μαζί με τα βοηθητικά αρχεία SQLite της σε ξεχωριστό κατάλογο. Δώστε στο αντίγραφο νέα διαδρομή `DB_PATH` και δικαιώματα `0600`. Εκκαθαρίστε τις αποκατεστημένες συνεδρίες πριν από επανεκκίνηση:

  ```bash
  node --input-type=module -e 'import {DatabaseSync} from "node:sqlite"; const db=new DatabaseSync(process.env.DB_PATH); db.exec("DELETE FROM sessions"); db.close()'
  ```

## Κόστος και περιορισμοί

Ο κώδικας χρησιμοποιεί Node.js, SQLite και Chromium χωρίς άδεια επί πληρωμή. Για πρόσβαση μέσω Internet απαιτούνται διακομιστής, HTTPS, αντίγραφα σε δεύτερο αποθηκευτικό χώρο και συνήθως ένα όνομα χώρου. Το κόστος εξαρτάται από τις υπηρεσίες που ήδη διαθέτει ο Όμιλος. Βλ. [αρχιτεκτονική](ARCHITECTURE.md) και [εγχειρίδιο διαχειριστή](MANUAL.el.md).

Η πλήρης συμβατότητα με το πραγματικό αρχείο θα επαληθευτεί στην ιδιωτική εγκατάσταση. Οι δοκιμές καλύπτουν τη δομή της v10.7 με 61 συνθετικές εγγραφές και Chromium σε mobile portrait και landscape. Χρειάζονται επιβεβαίωση διαχειριστή σε πραγματικό κινητό και tablet, δοκιμή του επιλεγμένου HTTPS host και δοκιμή επαναφοράς εκεί. Η εγκατάσταση έχει μία βάση σε έναν διακομιστή. Χρησιμοποιήστε αντίγραφα εκτός διακομιστή για ανάκτηση από βλάβη του τόμου. Η ανάκληση συνεδρίας γίνεται από την αποσύνδεση ή με αλλαγή κωδικού και επανεκκίνηση. Δεν υπάρχει αυτοεξυπηρέτηση επαναφοράς κωδικού.
